# 黑流树海战后奖励采集器

这是一个只读的 PC 画面采集工具，用于统计《明日方舟》集成战略“沉沦者的黑流树海”战斗结束后的资源奖励。

它不会点击、控制或修改游戏，只会：

1. 低频读取“明日方舟”窗口画面；
2. 识别稳定的“成功通过”和战后“收下”奖励页面；
3. 保存原始证据截图；
4. 离开奖励页面后弹出确认窗口；
5. 将审核结果追加到 JSONL、CSV 和分组汇总 JSON。

实时采集采用截图/OCR双线程：平时约每 0.55 秒采集一次并保留最近的预录帧；识别到结算或奖励页后切换为约每 0.18 秒一次的突发采集。截图先进入有界压缩缓冲区，OCR变慢时不会阻塞后续截图。

结算页后允许最多 30 秒的升级与过渡动画来等待奖励页；在奖励页出现前不会提前结束本场。奖励出现后，如果右上角重新出现地图专属的“行动力”UI，约 1 秒后生成确认弹窗；无法确认返回地图时，连续奖励卡之间仍允许最多 5 秒的动画或空白作为兜底。

## 安装

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

## 启动

先打开明日方舟 PC 客户端，再运行：

```powershell
.\.venv\Scripts\blackflow-reward-collector.exe
```

采集器会从页面顶部的区域名、罗马数字以及战前/结算页的类型文字自动缓存来源层数、所在环境和战斗类型。主窗口的预设值只作为识别不到时的回退，所有字段仍可在战后弹窗中修改。

目前自动识别：

- 玻利瓦尔肤层至源流交汇处对应的第 1～6 层；
- 页面顶部的 `(I)`～`(VI)`；
- 常规区域与“未萌生的摇篮/??”误入奇境内部；
- 狭路相逢、普通作战、紧急作战、险路恶敌/Boss、追猎；
- 流窜“居民”普通占领战与“居民”据点。

## 统计边界

- “误入奇境内部”是位置环境，不与普通/紧急/Boss 等战斗类别混为一个字段。
- 局内宝箱和宝物怪第一版不自动识别，战后必须选择“无、宝箱、宝物怪、两者都有、不确定”之一。
- 源石锭数量只读取当前奖励页明确展示的“源石锭 ×N”，并按同一卡片上方是否带有“无主的财富”标签，拆分为“普通源石锭”和“无主的财富源石锭”。
- 两类源石锭会分别写入记录；`originium_ingots` 只保存二者合计，避免将可信的普通掉落与额外掉落混在一个统计字段中。
- 收藏品、零件或宝物怪造成但未在奖励卡上显示的额外收益，由战后确认窗口人工补充；不使用资源总量的前后差值推断来源。
- 当前采集批次的指挥经验倍率默认预填为 `1.2`，仍可逐场修改。
- 直接“收下”的非源石锭、非招募券奖励会计为收藏品；“或是”选择页不会误计为两个收藏品。
- 零件数量通过同一奖励流程中“零件箱”已用容量的最小值与最大值之差计算。
- 结算通知“流窜‘居民’已经从林间消失”会将本场识别为居民占领战。
- 有额外来源但无法说明具体掉落的样本会保留证据，但不会进入基础奖励均值。
- “希望上限+6”“可携带干员数+1”等升级效果单独记录，不算作战斗随机掉落。
- 自动识别结果永远是预填值，只有点击“确认并保存”后才进入正式统计。

## 输出

默认写入：

```text
data/records/rewards.jsonl
data/records/rewards.csv
data/records/summary.json
data/records/screenshots/<sample-id>/
```

`rewards.jsonl` 是原始事实源；CSV 方便表格查看；`summary.json` 提供按层数、环境和战斗类型分组的基础统计。
